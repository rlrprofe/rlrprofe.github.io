    Cursos y manuales de desarrollo de software

    Aquí encontrarás los cursos que se van publicando para los módulos de desarrollo de aplicaciones. Cada curso es un sitio independiente, con sus capítulos, ejemplos y actividades.

    Cursos disponibles

    • Git y GitHub

      Guía práctica de control de versiones: instalación, ramas, fusiones, trabajo colaborativo, flujos profesionales y un proyecto integrador.

      Abrir el curso

    • Apache Maven · Minicurso práctico

      Crear, configurar, compilar y mantener proyectos Java con Maven, desde la terminal y desde VS Code, Eclipse e IntelliJ IDEA.

      Abrir el curso

    • Acceso a Datos · 2.º DAM

      Ficheros y formatos de intercambio, JDBC, componentes de acceso a datos y persistencia con ORM (Hibernate). Incluye un anexo de Maven.

      Abrir el curso

    • POO · Programación Orientada a Objetos

      Objetos y clases; encapsulación, herencia y polimorfismo; relaciones entre objetos y puente hacia los diagramas UML. Ejemplos en Java.

      Abrir el curso

    • UML · Modelado de sistemas

      Diagramas de clases y de comportamiento: del requisito al diagrama y del diagrama al código. Casos de uso, secuencia, actividades y estados.

      Abrir el curso
